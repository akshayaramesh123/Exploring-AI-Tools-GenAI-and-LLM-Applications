# Perplexity AI

## What is Perplexity?

Perplexity is an AI-powered answer engine that helps users search for information and receive conversational answers with supporting sources.

## Key Features

- AI-powered search
- Source-based answers
- Web research
- Question answering
- Information summarization

## Applications

- Research
- Education
- Learning new topics
- Information gathering
- Content research

## Advantages

- Provides sources for information
- Useful for research
- Saves search time
- Presents information in a conversational format

## Limitations

- AI-generated answers may contain errors
- Sources should be checked for reliability
- Results depend on the search query

## Example

**Prompt:** What are the latest applications of Generative AI in education?

**Use:** Perplexity can search for relevant information and present an answer along with supporting sources.
