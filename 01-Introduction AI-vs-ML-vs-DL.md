# AI vs Machine Learning vs Deep Learning

## Artificial Intelligence (AI)

Artificial Intelligence is the broad field of creating machines that can perform tasks requiring human-like intelligence.

## Machine Learning (ML)

Machine Learning is a part of AI where computers learn patterns from data and use them to make predictions or decisions.

## Deep Learning (DL)

Deep Learning is a subset of Machine Learning that uses neural networks with multiple layers to learn complex patterns from large datasets.

## Comparison

| Technology | Meaning | Example |
|---|---|---|
| AI | Machines performing intelligent tasks | Chatbots |
| ML | Learning from data | Spam Detection |
| DL | Learning using deep neural networks | Image Recognition |

## Relationship

AI → Machine Learning → Deep Learning

Deep Learning is a subset of Machine Learning, and Machine Learning is a subset of Artificial Intelligence.
