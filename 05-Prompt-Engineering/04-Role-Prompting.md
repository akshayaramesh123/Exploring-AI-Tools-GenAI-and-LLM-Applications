# Role Prompting

## What is Role Prompting?

Role prompting is a technique where the user assigns a specific role or perspective to an AI model before giving a task.

## Why Use Role Prompting?

Giving the AI a role provides context and helps guide the style and focus of the response.

## Example

**Prompt:**

You are a Data Science teacher. Explain Machine Learning to a beginner using simple examples.

## Common Roles

- Teacher
- Software Developer
- Data Analyst
- Career Advisor
- Research Assistant

## Advantages

- Provides clear context
- Helps produce focused responses
- Can improve the structure of answers
- Useful for learning and professional tasks

## Applications

- Education
- Programming
- Data analysis
- Content creation
- Interview preparation

## Conclusion

Role prompting is a simple technique for guiding an AI model by defining the role or perspective it should use.
