# AI Text Generator

## Project Overview

AI Text Generator is a simple Generative AI application that generates text based on a user's prompt.

## Objective

The main objective of this project is to understand how Generative AI models can be used to generate text from user inputs.

## Technologies Used

- Python
- Streamlit
- Transformers
- Generative AI Model

## How It Works

1. User enters a prompt.
2. The application sends the prompt to the AI model.
3. The model processes the input.
4. Generated text is displayed to the user.

## Features

- Simple user interface
- Prompt-based text generation
- Fast response
- Easy to use

## Learning Outcome

Through this project, I learned the basics of Generative AI, text generation, Python libraries, and building a simple AI application.
