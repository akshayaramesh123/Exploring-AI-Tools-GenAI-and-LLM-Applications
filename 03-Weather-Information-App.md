# Weather Information App

## Project Overview

Weather Information App is a simple web application that provides weather-related information to users.

## Objective

The objective of this project is to create an easy-to-use application for checking weather information and to understand the basics of web application development.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Simple user interface
- City-based weather search
- Weather information display
- Responsive design

## How It Works

1. User enters a city name.
2. The application processes the input.
3. Weather information is retrieved.
4. The result is displayed to the user.

## Learning Outcome

Through this project, I learned the basics of HTML, CSS, JavaScript, user input handling, and creating a simple web application.
