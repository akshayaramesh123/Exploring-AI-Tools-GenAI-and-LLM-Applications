# What is Generative AI?

## Definition

Generative AI is a type of Artificial Intelligence that creates new content such as text, images, audio, videos, and code based on user prompts.

## Examples

- ChatGPT
- Google Gemini
- Claude
- Microsoft Copilot
- Midjourney

## Uses

- Content Writing
- Image Generation
- Coding Assistance
- Education
- Customer Support
